# 계이름 계단 (musicstairs)

서양 음계 12음을 계단 한 칸씩에 대응시키고, 반음마다 30°씩 돌아 한 옥타브(12칸)가 정확히 한 바퀴가 되도록 만든 3D 인터랙티브 아트입니다.

- 각 음은 붐웨커 색을 가지며, 한 옥타브 위의 같은 계이름은 같은 색 계단 바로 위에 떠 있습니다.
- 계단(음판) 길이는 실로폰 막대처럼 진동수의 제곱근에 반비례(L ∝ 1/√f)해 위로 갈수록 짧아집니다.
- 계단을 누르면 소리가 나고, 클래식 곡을 재생하면 성부마다 다른 공이 계단을 오가며 궤적을 그립니다.

## 기능

- **곡 재생:** 성부마다 다른 공이 계단을 오가며 궤적을 그리고, 같은 음을 다시 만나면 도형이 닫힙니다. 재생 위치·빠르기 조절, 악기 선택(실로폰·피아노·현악기·오르간)
- **네온과 레이저:** 울리는 계단이 제 색으로 빛나고, 계단 방향 그대로 바깥으로 레이저가 뻗어 화음을 부채꼴로 보여 줍니다.
- **화음 이름과 기능:** 지금 울리는 화음의 이름(C, G7/B…), 화음 시계, 곡의 조 기준 로마 숫자(I, V⁷, V⁷/V…)와 으뜸·버금딸림·딸림화음 표시
- **화음 만들기:** 계단을 누르면 서스테인 페달처럼 음이 쌓여 함께 울리고, 마지막으로 누른 뒤 5초가 지나면 사라집니다. 다시 누르면 그 음만 빠집니다.
- **카메라:** 위에서 본 해바라기 모습으로 시작하는 오프닝, 오르며/내리며 자동 회전, 지금 그려지는 궤적을 따라가는 카메라워크
- **화면:** 전자칠판처럼 가로로 긴 화면에서는 양옆 패널 배치로 바뀌고, 계이름 버튼이 아래쪽에 크게 놓입니다. 카카오톡·네이버 등 앱 안 브라우저에서 열면 기본 브라우저로 다시 엽니다.
